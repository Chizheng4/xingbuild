# v0.26.5 页面独立内容接入与兼容重构方案

## 目标

在不影响线上 v0.26.4、既有 ContentSet、内容发布工具和运营流程的前提下，解除首页与 `/products` 的页面投影耦合。

```mermaid
flowchart LR
  A[内容对象<br/>Robotaxi / 其他作品] --> B[ContentResolver]
  B --> C[首页独立接入配置]
  B --> D[/products 独立接入配置]
  C --> E[首页自己的页面组合]
  D --> F[/products 自己的页面组合]
  G[共享基础组件与 tokens] --> E
  G --> F
```

## 根因

当前 HomeComposition 与 ShowcaseComposition 虽然注册入口分开，但共同调用 `ShowcaseFlow → PracticePresentation`；该组件同时持有 `sectionLabel`、`heroAlign`、`actions`、`showClosing` 等页面级结构开关，导致页面投影耦合。

## 正式架构合同

### 页面独立

- 首页和 `/products` 各自拥有独立 IA、布局、组件组合、交互语义和生命周期。
- 首页可以通过自己的内容接入能力按需引用 Robotaxi 或未来其他作品；`/products` 独立决定自己的内容接入。
- 一页的结构、视觉、CTA、ClosingAction 或生命周期变更不得强制影响另一页。

### 可共享能力

- `ContentResolver`、内容对象读取、基础展示组件、MediaStage、ActionGroup、tokens、媒体安全链接和空内容降级能力可以共享。
- 共享能力只提供无页面语义的能力，不保存另一页面的结构开关。

### 禁止共享

- 不共享页面投影组件作为页面级编排器；不共享 `sectionLabel`、`heroAlign`、`actions`、`showClosing` 等页面组合状态。
- 不使用 `shared-content-projection` 或“统一投影”作为页面契约。
- 不复制内容正文、审核、来源、媒体事实或 ContentSet 身份。

## 兼容与迁移

- v0.26.4 继续在线并继续承载内容运营；本版本只在本地和预发布 ProductArtifact 验证。
- 既有 ContentSet 字段、ContentReleaseId、mediaId、ContentSet Candidate、SitePublication Coordinator 入口保持兼容。
- 不要求既有内容重新 prepare/build/transport；内容只需通过页面接入槽位读取。
- 页面缺少可选内容时显示既有合法 empty/fallback，不制造占位内容。
- 如果必需接入槽位、字段语义、路由或媒体合同不兼容，产品 transport 前硬失败并生成 Product Incident；不得让内容 task 手工修补。
- 新版本验证失败时，线上保持 v0.26.4，不切换、不污染 active ContentSet。

## Engineering 实现边界

1. 拆分首页与 `/products` 的页面编排入口，使其不再共同持有页面级 `PracticePresentation` 状态。
2. 保留共享无页面语义 primitives 和 resolver；页面专属配置由各自 composition 持有。
3. 为每个页面定义明确的 `contentRefs`、显示槽位、CTA、ClosingAction、empty 状态和媒体投影配置。
4. 更新 `pageDefinitions`，移除 `shared-content-projection` / `统一投影` 语义。
5. 不新增第二套 CSS、第二套内容发布器或第二套生命周期。

## 验收

- 修改首页页面编排的 fixture/配置不会改变 `/products` DOM、CTA、ClosingAction 或布局；反向同理。
- 两页可以读取同一 Robotaxi 对象，但页面结构和页面级文案可不同。
- 新增一个作品对象只需增加内容引用，不复制页面组合。
- 删除可选内容后两页分别显示合法 empty/fallback，且无空白占位。
- 五路由 Web `1600×1067`、Mobile `390×844`、窄屏 `320×844` 无横向溢出，每页一个 H1、无 console/page error。
- 既有 38-entry ContentSet、33 条观察、article/profile/businessObservation/practice 身份不变。
- 产品与内容发布均保持既有入口；内容 task 不改产品代码。
- `npm run check`、分层 QA、`release:prepare`、`release:build`、`release:closeout-check`、`release:preflight`、真实 Web→Mobile 视觉验收和公网验证全部通过后才允许切换。

## 不做

- 不修改 v0.26.4 或更早 tag/history。
- 不暂停或重发既有内容。
- 不改变内容正文、审核、来源、媒体、ContentSet、SitePublication 或 Coordinator 事实。
- 不创建分支、worktree、并行发布器或替代 task。
