# xingbuild v0.14.0 浮动导航、排版层级与移动归属收口方案

## 1. 结论

本轮不是重新设计网站，也不是继续用局部 margin 修补。目标是把已经成立的 v0.13 展示母版补齐为一个稳定的“层级归属系统”：

1. Header 在滚动后成为可感知、但克制的上层导航；
2. 首页定位语真正拥有完整 shell 行，观察 Rail 从下一层才开始；
3. 字体、字号、行高和颜色按内容角色统一，不再由页面各自决定；
4. 首页与来源页使用同一个产品/经营观察 Presentation，仅改变语义标题层级；
5. 手机端用明确的对象内/对象间间距比例绑定图与解释；
6. 删除读者不需要的 career/版本治理说明；
7. 同步设计事实源，避免后续 task 重复或遗漏。

参考 Maggie Appleton 只学习机制：每个阅读层只有一个主角、次级信息明显退后、相邻关系稳定。不得复制其品牌外观或约 82px 的大标题。

## 2. 当前线上证据与根因

### 2.1 Header

线上 Header 已是 `position: sticky`，桌面高 56px，但滚动前后：

- `box-shadow: none`；
- `backdrop-filter: none`；
- 背景与页面完全相同；
- 没有滚动状态。

因此导航虽然固定，视觉上却没有“内容向它下面收进去、导航浮在上层”的反馈。

### 2.2 首页

当前定位语 H1 与 Rail 同时位于 `TwoColumnLayout`，1440px 下两者都从 y=88 开始。定位语只占主栏，不是完整 shell 行。

根因是页面对象层级错误，不是定位语 max-width 或 margin 单点错误。

### 2.3 排版

现有 `--type-page-title` 最大 34px，同时被 Robotaxi、企业经营体系、观察、关于我和首页投影使用；首页定位语最大仅 28px。角色关系不够清楚，且首页投影的模块标题语义层级没有随上下文下降。

### 2.4 手机图与解释

移动断点把 Stage 放到说明之前是正确的，但对象内部 gap 当前为 24px，与对象/后续内容间距的差异不够显著。长解释向下滚动时容易被误认为下一对象的标题或说明。

## 3. 固定视觉方向

### 3.1 颜色责任

| 角色 | 颜色 |
| --- | --- |
| `xingbuild`、页面/对象标题、正文 | `--color-text` 暖墨色 |
| 作者、摘要、元信息、来源 | `--color-text-muted` |
| 当前导航、选中节点、hashtag dimension、focus/hover | `--color-accent(-strong)` |

不把 `xingbuild` 或页面标题整体改成赭红。永久品牌如果使用选中态颜色，会与当前导航争夺状态语义。

### 3.2 排版角色

以下是角色合同，不允许页面私有字号覆盖：

| 角色 token | 桌面 | 手机 | 字体/责任 |
| --- | --- | --- | --- |
| `--type-wordmark` | 28px / 1 | 24px / 1 | Georgia；紧凑站点身份 |
| `--type-positioning` | 32px / 1.45 | 24px / 1.42 | 宋体；首页唯一主表达 |
| `--type-page-title` | 28px / 1.36 | 24px / 1.38 | 宋体；Robotaxi、企业经营体系、观察、关于我 |
| `--type-article-title` | 32px / 1.4 | 26px / 1.42 | 宋体；只有真正长文 |
| `--type-section-title` | 18–20px / 1.45 | 18px / 1.45 | 宋体；产品模块、RichDocument H2 |
| `--type-reading` | 16–17px / 1.85 | 16px / 1.8 | 宋体；正文/Observation body |
| `--type-summary` | 16px / 1.7 | 15–16px / 1.7 | 黑体/无衬线；摘要说明 |
| `--type-meta` | 13px / 1.55 | 12–13px / 1.55 | 无衬线；日期、维度、来源、作者 |

标题是否是 H1/H2/H3 由所在页面上下文决定，视觉角色不随标签改变。

### 3.3 标题语义

| 页面 | 标题结构 |
| --- | --- |
| 首页 | H1 定位语；最新 B端产品 H2；产品模块 H3；最新经营观察 H2；选中概念 H3 |
| B端产品 | Robotaxi运营平台 H1；产品模块 H2 |
| 经营观察 | 企业经营体系 H1；选中概念 H2 |
| 集中观察 | 观察 H1；Brief subject 不是文章标题 |
| 关于我 | 关于我 H1；RichDocument H2/H3 |
| 长文 | Article title H1；RichDocument H2/H3 |

不额外显示“大号 B端产品/经营观察”分类标题，也不把页面标题改成红色小标签。页面首个真实内容对象本身就是身份。

## 4. Header 滚动状态

### 4.1 状态

`top`：

- 高度保持 56px / 52px；
- 与 canvas 一体；
- 无 shadow；
- 不改变 wordmark、作者或导航位置。

`scrolled`（页面滚动超过 8px 或顶端 sentinel 离开）：

- full-viewport 暖白半透明背景，建议 `rgba(245,241,232,.94)`；
- `backdrop-filter: blur(12px) saturate(.96)`；
- 一条极弱关系线和轻影，例如：
  `0 1px 0 rgba(80,58,39,.06), 0 8px 24px rgba(60,44,30,.07)`；
- 160ms 颜色/阴影/透明度过渡；
- Header 高度和页面几何绝对不变化；
- `prefers-reduced-motion` 取消过渡。

用 Header 全视口伪元素或等价外层承载背景和影子；不能只让 1280px 内层出现一截阴影。

## 5. 首页结构

必须调整为：

```text
LayoutShell
├─ HomePositioning（完整 shell 行）
└─ TwoColumnLayout
   ├─ main
   │  ├─ LatestProductProjection
   │  └─ LatestBusinessObservationProjection
   └─ ObservationRail
```

规则：

- HomePositioning section 占完整 shell；
- 文字 measure 建议最大 64rem，不等于铺满 1280px；
- 定位语与下一层 TwoColumnLayout 使用 `--rhythm-section`；
- Rail 顶部从最新 B端产品投影开始，不得进入定位语行；
- 首页仍只有一个 Rail；
- 首页不得复制来源页的标题、摘要、模块或框架 JSX。

## 6. Presentation 与组件责任

### 6.1 产品

保留 `PracticePresentation`，增加根标题层级向下传递：

- 来源页根 H1 → 模块 H2；
- 首页根 H2 → 模块 H3。

### 6.2 经营观察

新增唯一 `BusinessObservationPresentation`：

- 负责标题、读者需要的短摘要和 `FrameworkExplorer`；
- 来源页与首页消费同一个组件；
- 只通过 `headingLevel` 改变语义标签；
- 删除首页手工 `home-page__business-header` 拼装。

### 6.3 治理边界

公开页面删除：

> 网站只组织当前表达快照；正式定义、层级关系和版本以 career 项目当前基线为准。

career 继续作为内部事实源。网站不得改写固定概念，但读者不需要理解仓库、版本与证据治理。

## 7. 手机图形与解释归属

### 7.1 共用比例

- 同一对象 `SystemStage → explanation`：12–16px；
- 不同产品模块之间：40–48px；
- Framework 完整对象 → 后续 ObservationRail：40px 以上；
- 对象内间距必须不超过对象间间距的三分之一左右。

### 7.2 Framework

手机仍保持：

```text
GraphCanvas
SelectedNodeExplanation
```

SelectedNodeExplanation：

- 紧邻 GraphCanvas；
- 使用轻暖状态面、无边线、无重阴影；
- 增加 12px 无衬线状态标识“当前节点”；
- 节点名使用 section-title；
- 定义、作用、直接关系只读取 `frameworkModel`；
- 不改写、不概括、不补造概念；
- aria-live 继续同步选择变化。

桌面仍是208px说明列 + 20px + GraphCanvas，不增加图下解释。

## 9. 验收合同

### 9.1 Header

- 1440/390 顶部状态 shadow 为 none；
- 滚动 100px 后 Header 高度、x/y 不变化；
- 滚动态 `box-shadow != none` 且 full viewport 连续；
- 内容从 Header 下方通过，不能覆盖导航；
- wordmark 仍为 ink，只有当前导航为 accent；
- reduced-motion 下没有过渡。

### 9.2 首页

- 1440 H1 所在 section 宽度为完整 LayoutShell；
- Rail top 必须低于定位语 section bottom；
- H1 只有一个；
- 标题顺序满足 H1 → H2 → H3；
- Robotaxi/企业经营体系正文与来源页来自同一组件/对象；
- 无横向溢出。

### 9.3 排版

- 计算样式符合角色表，不允许页面私有固定字号；
- Robotaxi、企业经营体系、观察、关于我的 H1 使用同一 page-title token；
- 首页定位语明显高于正文、但不使用 display hero；
- 来源/作者/日期保持 muted；
- 页面标题不使用 accent。

### 9.4 手机归属

- 390/320 Stage 在说明之前；
- Stage bottom 到说明 top 为12–16px；
- 当前对象说明 bottom 到下一对象 Stage top 为40–48px；
- Framework 当前节点状态面紧邻图且选中后同步；
- 不产生横向滚动、遮挡或内容裁切。

### 9.5 完整验证

- 1440、1024、768、557、390、320；
- 首页、B端产品、经营观察、集中观察、长文、关于我；
- Header top/scrolled、手机菜单、Framework click/keyboard/pan/reset；
- console error/warning = 0；
- `npm run release:check`、`git diff --check`、closeout/preflight；
- 按本轮授权发布后，必须在 `https://xingbuild.top/` 做1440、390、320公网验收。
