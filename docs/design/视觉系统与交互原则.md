# 视觉系统与交互原则

- 桌面端：暖白底、编辑型衬线标题、克制的赭色强调、横向架构关系。
- 手机端：保持同一暖白、墨色和赭色品牌体系，使用更清晰的无衬线层级与纵向架构流程。
- 同一内容模型、同一组件语义，通过响应式布局呈现，不维护两套页面。
- 响应式断点只改变布局、密度、排版、导航和图形方向，不重新定义全局品牌颜色；同一页面缩放时不得发生背景和强调色跳变。
- 高级感来自字体、留白、网格、比例和精确线条，不使用手绘、水彩、草图、做旧纸张、植物、风景或装饰性隐喻。
- 架构图优先表达对象、顺序、关系、反馈和边界；不为视觉效果添加无业务含义的节点。
- 一级导航固定为“观察 / 作品 / 关于我”。
- 首页不使用三个等宽栏目卡片；桌面采用编辑型网格，手机采用单列系统型布局。
- 观察列表使用日期、主题、标题组成的紧凑归档；长文使用受控正文宽度和稳定阅读节奏。
- 关于我桌面采用页内目录与分区正文，手机改为单列目录和内容。
