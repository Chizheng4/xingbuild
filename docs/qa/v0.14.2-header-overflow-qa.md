# v0.14.2 Header 横向溢出 QA

## 固定合同

- Header 背景是固定视口层，使用 `inset-inline: 0` 的等价几何，不得使用 `100vw` 或水平位移扩展文档宽度。
- Header 继续使用既有 56px / 52px 高度、滚动后暖白半透明背景、12px blur 与轻影；降动效无过渡。

## 验证记录

- 自动：Header 样式合同拒绝 `100vw` 与 `translateX(-50%)` 回归；完整发布检查、差异检查、收口和发布预检通过。
- 浏览器：1440、1024、390 的首页与企业经营体系来源页均验证 `documentElement.scrollWidth === documentElement.clientWidth`；1440 来源页滚动后 Header 实测保持固定背景层、暖白 `rgba(245, 241, 232, .94)`、`blur(12px) saturate(.96)` 与相等文档宽度。1024/390 的滚动态由同一固定伪元素与既有滚动状态合同覆盖；控制台 error/warn 为 0。

未使用 `overflow-x: hidden`，不改变 Header 与页面内容的任何视觉值。
