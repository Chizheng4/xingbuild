- 五个视口的全部页面均无横向溢出；320px 初检发现的 15px 溢出已通过移除基础层硬性最小宽度修复，回归结果为 0。
- Noto Serif SC Variable 与 Noto Sans SC Variable 均由本地依赖加载，`document.fonts.status` 为 `loaded`，中英文检查均返回可用。
- 1440px 首页展示标题 68px；390px 首页展示标题 38px、页面标题 36px；手机正文 16.5px、行高 32.175px。
- 全站可见小字下限为 11px；必要元数据不低于 12px；手机架构图标题为 14px、说明为 12px。
- 长文正文宽度在 390px 视口为 339px，桌面最大阅读宽度受 720px 语义版心约束。
- 390px 菜单覆盖完整 390×844 视口，打开时锁定页面滚动并将正文设为 inert；菜单链接高度为 56px。
- 手机目录折叠触控高度为 46.4px，能够展开全部三级阅读入口。
- 主要颜色对比度：正文/画布 14.34:1，弱化文字/画布 5.65:1，强调色/画布 5.51:1，强强调色/画布 8.13:1。
- 浏览器控制台没有错误或警告；只有 Vite 连接日志与 React 开发工具提示。
