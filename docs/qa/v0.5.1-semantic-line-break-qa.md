Chrome 已计算 `word-break: auto-phrase`，但单独依赖该属性时仍会在部分宽度拆词。因此保留统一 CSS 合同，并由内容语言层使用 Unicode WORD JOINER 标明经真实验收确认的不可拆词组。该约束不产生固定换行，不按视口改变文案，也不依赖 JavaScript 或第三方分词。

## 相邻内容节奏

- 标题 → 第一段：16px；
- 同一论述段落 → 段落：24px；
- 章节 → 下一章节：由 `--space-reading-section` 单方控制；
- 元数据 → 文章标题：16px；
- `SectionIntro` → 第一项：由页面编排的 `--space-content-entry` 单方控制；
- 正文块清零双边 margin，章节建立独立格式化上下文，不依赖 margin collapse。

## 回归结果

- 1440px 和 390px 已回归首页、观察列表、长文、作品列表、Robotaxi 作品详情与关于我；
- 557px 与 520px 保持行内导航；390px 菜单覆盖完整视口、切换关闭状态并锁定背景滚动；
- 首页 Hero 起点、字体角色、颜色、内容结构和阅读宽度未改变；
- 关键页面控制台无 error 或 warning；
- `lang="zh-CN"` 在所有关键页面生效。
