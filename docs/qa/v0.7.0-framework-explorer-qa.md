## 真实浏览器

验证视口：1440×1000、1024×768、768×1024、557×900、520×900、390×844、320×568。

结果：

- 1440 与 1024 保持主结构和 360–400px 右侧稳定详情；
- 768 以下进入单列，详情不以遮挡层或内部滚动容器出现；
- 557 与 520 保持紧凑行内导航，390 与 320 使用全屏手机菜单；
- 七档均保持暖白背景、墨色正文，标题和结构无横向溢出；
- 手机节点进入独立概念页，返回路径可读，触控目标满足 44px；
- 六步下钻、浏览器返回、Escape 清除桌面选中态和手机菜单滚动锁定通过；
- Robotaxi 应用显示认知映射和“非真实城市经营结果”的证据边界；
- 浏览器控制台没有错误或警告。
