# 当前迭代

## 当前稳定版本

`v0.3.1`

## 目标版本

`v0.4.0`

## 要解决的问题

- 当前视觉方向成立，但颜色、字号、空间和响应式规则还没有形成完整语义 token。
- 手机端整体切换无衬线，桌面与手机的编辑型品牌连续性不足。
- 必要元数据和架构说明仍存在 9px、10px 小字。
- `App.jsx` 与单一 `styles.css` 承担过多页面和视觉责任，后续迭代容易产生漂移。

## 本轮范围

- 实施 `xingbuild Visual System v1`。
- 建立色彩、字体、字号、行高、空间、版心和断点 token。
- 保持桌面和手机一致的字体角色，重算而不是缩放页面。
- 最小充分地拆分稳定页面、组件和 CSS 责任。
- 完成首页、观察、正文、作品和关于我的视觉适配。
- 增加视觉系统合同测试与五个视口真实浏览器验证。

设计事实源：

- `docs/design/xingbuild Visual System v1.md`
- `docs/design/v0.4.0 视觉系统工程化升级方案.md`
- `docs/design/v0.4.0 Engineering task 执行指令.md`

## 明确不做

- 不改变网站名称、作者身份、一级导航和内容事实。
- 不增加深色主题、CMS、搜索、筛选、Build Log 或自动分发。
- 不复制 Maggie Appleton 的字体和视觉资产。
- 不推送 GitHub、不发布 EdgeOne、不修改域名。

## 涉及对象和文件

- 视觉对象：颜色、字体、字号、行高、空间、版心、断点和交互状态。
- 页面：首页、观察列表、短观察、分析长文、作品列表、作品详情、关于我。
- 工程责任：`src/App.jsx`、稳定页面和组件、`src/styles.css` 与新样式模块、视觉合同测试。

## 验收标准

- Visual System v1 token 成为视觉事实源。
- 桌面与手机共享同一品牌颜色和字体角色。
- 正文、标题、元数据和架构说明符合字号、行宽和对比度合同。
- 1440、1024、768、390、320 五个视口无整页横向溢出。
- 手机菜单、手机目录和架构图保持可用、可读。
- 自动检查、设计 QA 和 `npm run release:check` 通过。

## 当前状态

Visual System v1 已完成工程实现、五档视口真实浏览器验证、设计 QA 与 `npm run release:check`；本轮本地稳定版本已关闭，未推送 GitHub、未发布 EdgeOne。
