# v0.15.3 ObservationRail 从属预算与跨 task 边界修订

## 问题

双栏 Grid 默认 stretch 会让 ObservationRail 反向决定主栏高度；Rail 又使用被撑高后的主栏预算并强制至少一项，造成可见项密度和对象从属关系失真。

## 实现

- 双栏显式 `align-items: start`，主栏 intrinsic content height 成为 Rail 的单向预算来源。
- Rail 预留真实 brief gap 与“更多观察”高度，只显示完整项，允许零项；隐藏测量层不进入辅助技术树或交互树。
- `/products` 的 Practice modules 为零时不挂载 Rail；首页和企业经营体系继续使用同一 Brief anatomy 的从属投影。
- Rail 仅收紧 statement 的现有 UI type role；集中 `/observations` 的 anatomy、字号、间距和密度保持不变。
- 记录跨 task 有界交接与浏览器资源释放规则，不新增工具或自动归档系统。

## 验收

- 主栏尺寸不受 Rail 反向拉伸；Rail 含“更多观察”的总高度不超过预算，零项可成立。
- Products 零模块时无 Rail、无 Brief、无媒体或空框；首页与企业经营体系的 Rail 不回退。
- 自动测试、release check、差异检查和串行本地浏览器验证通过；本版本只完成本地收口，不推送或部署。
