# v0.5.2 修正本地启动与交付链接

## 解决的问题

- 双击启动指令后只启动服务，不会自动打开网站；
- 4317 被占用时 Vite 会静默切换端口，但脚本仍显示旧网址；
- 每轮完成报告没有固定提供本地与线上可点击入口。

## 完成范围

- 已有正常服务时复用并直接打开；
- 没有服务时固定使用 4317 启动并自动打开浏览器；
- 异常端口占用时停止并明确提示，不再静默漂移端口；
- 启动终端及迭代完成报告同时提供本地与线上网址；
- 保持本地验证、GitHub 推送与 EdgeOne 生产状态相互独立。

## 验证结果

- 脚本语法检查通过；
- 无服务时在 4317 成功启动；
- 已有正常服务时成功识别、复用并执行打开动作；
- 端口异常占用路径能够明确停止；
- `npm run release:check` 通过。

## 完成状态

- 本地提交与 `v0.5.2` 标签已完成；
