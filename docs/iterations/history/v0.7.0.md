# v0.7.0 企业认知框架产品化

## 目标

在不重造 career 权威概念、不形成第二事实源的前提下，把企业经营体系认知框架从长文档和静态作品说明升级为可下钻、可追溯、可返回的框架浏览器。

## 完成范围

- 一个概念、关系、视图、应用和路径状态模型驱动全部页面投影；
- 总览、数字化实现、企业业务架构九视角、业务对象、对象与 Robotaxi 应用；
- 桌面非遮挡双区、900px 以下单列语义流和手机独立概念页；
- 稳定 URL、前进后退、来源视图与滚动恢复、hover/focus/click 等价、Escape 和状态通知；
- 关系文本等价物、上游版本、Robotaxi 证据边界与无 JavaScript 可读顺序；
- 模型完整性、核心路径、路由交互和响应式合同自动测试。

## 验收

- `npm run release:check` 通过，28 项测试全部通过；
- 1440、1024、768、557、520、390、320px 真实浏览器验证通过；
- 完整路径“总览 → 数字化实现 → 企业业务架构 → 业务对象 → 对象 → Robotaxi 应用”通过；
- 320px 无整页横向滚动，520px 导航合同、固定浅色品牌和控制台均通过。
