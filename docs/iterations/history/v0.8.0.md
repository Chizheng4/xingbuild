# v0.8.0 单页交互式企业认知架构

## 问题

原企业认知框架由入口页、框架浏览器、视图切换和独立概念页组成，文字和路径过多，架构关系没有成为页面主体。

## 实现

- 将企业认知框架重构为由四个核心问题和四张完整架构图组成的连续单页；
- 建立共享的 Architecture、Node、Edge、RelationLabel、NodeExplanation 与响应式投影模型；
- 桌面使用左图右解释，900px 以下使用图后解释，桌面和手机消费同一节点与固定边集；
- hover/focus 提示可点击和直接关系，click/Enter/Space 更新稳定解释；
- 分离无箭头 routing track 与进入真实节点的有向边，每条关系文字对应唯一边；
- 旧深层 URL 归一到唯一公开页，删除公开视图切换和独立概念路径；
- 保留无 JavaScript 可读顺序、键盘可访问性、语义焦点和移动端完整架构。

## 验证

- `npm run release:check` 通过，30 项测试全部成功；
- 真实浏览器验证覆盖 1440、1024、768、557、520、390、320px；
- 四图节点、固定边集、箭头目标、关系文字唯一性和桌面/手机语义同源均通过自动校验；
- 结构视觉 task 独立复验结构、视觉、响应式、交互与浏览器控制台，专业验收通过；
- 320px 无节点越界或整页横向滚动，390px 全屏菜单、滚动锁定和 Escape 关闭正常。

## 已知边界

- 1024px 是双区桌面结构的高密度边界，但节点、关系和解释仍可读；
- 四图采用固定内容模型和受控 SVG 投影，不提供拖拽、缩放、编辑或自动布局；
- 图四在手机端纵向较长，以保持完整语义和可读节点。
