# v0.6.0 视觉结构与空间节奏系统

## 解决的问题

- 页面缺少从 Page Frame 到 Relationship 的稳定结构层级；
- 相邻栏目由上一栏目的尾部空间和下一栏目的头部空间共同控制，形成约 256px 的双重边界；
- Identity、Proposition、Evidence 和 Action 等对象内部关系集中在相近的小间距，阅读分组不清；
- 页面专用间距难以指导内容增长和跨页面复用。

## 完成范围

- 建立 Page Frame → Section → Content Group → Content Object → Element → Relationship 六层结构；
- 建立 `bind / relate / object / group / section` 五级语义关系 token；
- 建立 PageStack、SectionFlow、CollectionFlow 和 ObjectStack 最小布局责任；
- 让相邻栏目、栏目引导与正文、集合对象、对象内部语义组分别由共同父级单一拥有间距；
- 将首页、观察、作品、关于我和长文投影到同一结构合同，不改变内容事实、品牌或路由。

## 验证结果

- 1440、1024、768、557、520、390、320px 七档 Chrome 相邻边界验收通过；
- 桌面栏目边界进入 96–128px，紧凑与手机宽度平滑收敛到 64–78px；
- 关键页面无横向溢出，导航断点、手机全屏菜单和手机折叠目录未回退；
- 自动测试、生产构建、Sites 构建合同和 `npm run release:check` 通过。
