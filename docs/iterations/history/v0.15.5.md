# v0.15.5 全站 SiteShell 与 Footer 几何

## 问题

`.site-shell` 只有最小视口高度，没有纵向页面框架；短页的 `main` 不占剩余空间，Footer 因此停在内容之后而不是视口底部。

## 实现

- 全站 SiteShell 使用纵向 flex，Header 与 Footer 保持普通文档流，`main` 统一吸收剩余高度。
- 保留现有最大宽度、gutter、sticky Header、Footer 内容与全局关系间距。
- 使用 `100vh` fallback、`100dvh` 与移动端 `safe-area-inset-bottom`，不使用 fixed、absolute 或页面级补丁。
