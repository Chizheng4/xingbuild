# v0.14.3 Brief 正文合同统一修订

## 问题

`v0.13.1` 为八个当时尚未扩写的公开 Brief 设置了固定 slug 迁移豁免。它避免自动改写事实，却让内容完整后仍存在与日常 content-only 发布相冲突的工程例外。

## 实现

- 八条 Brief 已先通过独立 content-only 提交扩写为 80–160 中文等价字符；本修订不改写其内容。
- 删除固定 slug 迁移豁免；校验器以显式 `brief.body` 或 `brief.statement` 作为同一读者正文并统一执行长度合同。
- 测试改为验证全部 published Brief 与未来简讯均受相同合同约束。

## 验证

- 自动：`npm run release:check`、`git diff --check`、`npm run release:closeout-check`、`npm run release:preflight`。
- 公网：确认产品版本为 `v0.14.3`，八条已发布 Brief 仍在 manifest 与观察流中。

## 明确不做

- 不修改页面、视觉、信息架构、ObservationBlock、Rail、来源或任何 Brief 的事实正文；不增加新的内容例外。
