# v0.13.1 生产阅读合同修订

## 问题

`v0.13.0` 的生产验收暴露了四类共享合同未落地：首页仍使用 display Hero 字号；Brief 未形成真正的阅读信息块；观察上下文返回没有随入口传递；RichDocument 同时由父级和子元素拥有相邻间距。

## 实现

- 首页唯一 H1 仍读取 `site.homeTitle`，但以紧凑定位层级呈现：桌面 26–28px、手机 24–26px。
- ObservationBlock 以独立暖色 surface token 表达同一内容对象；无边线、阴影、抬升或装饰分隔。identity 固定单行，dimension 独占一行，来源保持弱色。
- Rail、集中观察和长文使用安全的 `origin` / `returnTo` 合同；返回标签按实际目的地生成，外部和协议相对路径被拒绝。
- ReadingShell 与 RichDocument 改为单点相邻关系：H1→lead 为 12px，lead→首 H2 为 32px；Article 与 About 共用该责任。
- 后续 Brief 的正文强制为 80–160 中文等价字符、主体最多 16；八条已发布短 statement 仅凭固定 slug 且缺失新 body 的组合获得迁移豁免，不自动扩写或改写事实。

## 验证

- `npm run release:check`、`git diff --check`。
- 真实浏览器：1440px 首页定位 28px；390px 首页定位 24px、About 相邻关系 12/32px；320px Brief identity 全部单行且无横向溢出；1440px 集中观察存在正确返回 B端产品与固定经营观察入口；390px legacy Article 传递正确 returnTo。
- 框架总览的选择交互和 1440px/390px 无横向溢出回归。
