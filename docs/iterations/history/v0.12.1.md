# v0.12.1 Robotaxi approved-media 内容入口

## 问题

`v0.12.0` 已建立 Robotaxi 作品页面母版，但没有可展示的经批准真实媒体。上游批准清单同时要求保留读者可见媒体、可选互动和不默认展示的内部溯源，旧内容合同无法表达这三类责任。

## 实现

- 仅从 Robotaxi `50d452f5` 的 `media/evidence-approved/manifest.json` 接入四项 approved/public 资产；本地导入前逐项核验审批记录、行—资产映射、禁止深链和 SHA-256。
- Practice 内容恢复上游 `group`：`运营中控台` 包含 `当前模拟运行` 与 `城市空间迭代`；`经营模型`、`经营总览` 保持独立模块。
- 内容合同分为 `media`（图片与未来视频）、`action`（当前四项全框访问 Robotaxi 独立系统）与 `provenance`（媒体角色、状态边界、版本、Git commit、哈希和审批）。
- 建立共享 InteractiveMedia：只有 action 存在时媒体框才是新窗口安全链接；无 action 的媒体不呈现可点击状态。
- 标题树：页面 h1 → 多项 group h2 → group 内 module h3；单项 module 仍为 h2。视觉字号与空间 token 保持一致。

## 验证

- `npm run release:check` 通过，52 项自动测试全部成功；`git diff --check` 通过。
- 1440px：无横向溢出，运营中控台作为唯一组标题，四项媒体保持桌面左说明、右 16:10 图和外链安全属性。
- 390px：四项图框均为 335×209，图上文下、无横向溢出；console warning/error 为 0。
- 专业验收确认批准媒体、事实边界、内部 provenance 与互动合同无回退。
