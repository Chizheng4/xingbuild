# v0.14.2 Header 视口背景溢出修订

## 问题

`v0.14.1` 的 Header 全宽背景伪元素以 `100vw` 和相对壳体的水平位移实现。垂直滚动条出现时，视口宽度与文档内容宽度不同，伪元素扩大了横向滚动范围。

## 实现

- Header 背景层改为固定定位的视口层，使用 `inset: 0 0 auto` 与显式 Header 高度，不再使用 `100vw` 或 `translateX`。
- 桌面与移动端分别从既有 Header 高度 token 取得背景高度；scroll 状态的暖白透明背景、12px blur、轻影和降动效合同不变。
- 增加样式合同，防止 Header 背景回退为文档宽度参与者。

## 验证

- 自动：`npm run release:check`、`git diff --check`、`npm run release:closeout-check`、`npm run release:preflight`。
- 浏览器：1440、1024、390 的首页与企业经营体系来源页均在滚动前后验证 `scrollWidth === clientWidth`，并验证 Header 滚动态仍成立。

## 明确不做

- 不使用 `overflow-x: hidden` 掩盖问题；不修改 Header 几何、标题、内容、信息架构、FrameworkModel 或视觉值。
