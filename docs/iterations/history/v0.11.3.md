# v0.11.3 Brief 事件日期与稳定排序修订

## 问题

ObservationBriefProjection 曾把 `publishedAt` 投影为列表日期并据此排序。多条不同事件在同一日 promote 时，读者只能看到相同的公开日期，信息流失去事件时间语义，且同日顺序不稳定。

## 实现

- 明确字段责任：`eventAt` 是 Brief 的读者时间，`publishedAt` 是公开发布与追溯时间。
- explicit brief 必须由具有有效 `eventAt` 的 ObservationPublication 提供；旧无 brief 文章不受影响，未来无事件日期的文章不能进入简讯流。
- Brief 查询按 `eventAt` 倒序、`publishedAt` 倒序、id 升序稳定排序；页面 time 元素只显示 `eventAt`。
- 补充 schema、验证器、投影、排序与页面日期合同测试。

## 验证

- `npm run release:check` 通过，51 项自动测试全部成功；
- `git diff --check` 通过；
- 专业复验确认 eventAt/publishedAt 分层、稳定排序和内容-only 边界成立。
