# v0.14.0 浮动导航、排版层级与移动归属收口

## 问题

`v0.13.1` 已建立信息架构与展示母版，但 Header 缺少滚动阅读层级，首页定位语仍与内容 Rail 竞争首行，标题层级与手机图文归属尚未由共享合同统一。

## 实现

- Header 维持既有 56px / 52px 几何；超过 8px 滚动后仅改变全视口背景层、轻影和模糊，降动效时无过渡。
- 新增并消费全站排版角色：wordmark、positioning、page title、article title、section title、reading、summary、meta。
- 首页唯一定位 H1 成为完整 shell 行；Robotaxi 与企业经营体系分别以同源 Presentation 投影在其后的内容主栏，Rail 保持一次且由真实 Brief 决定。
- Practice 模块标题按 Presentation 根标题自动递进；企业经营体系移动端以 14px Stage→当前节点解释关系呈现，解释只消费 `frameworkModel`。
- 移除面向读者的 career/版本治理说明；内部事实源、approved media provenance、ObservationPublication 与 frameworkModel 合同保持不变。

## 验证

- 自动：`npm run release:check`、`git diff --check`、`npm run release:closeout-check`、`npm run release:preflight`。
- 浏览器：1440、1024、768、557、390、320 宽度验证 Header 两态、首页完整定位行、标题层级、手机图文归属、框架选择/平移/复位、观察/长文/About 回归、无横向溢出和零控制台错误。

## 明确不做

- 企业经营体系局部视图；legacy Article / ArticlePreview 闭环；八条 Brief 扩写；About 事实补齐；controlled-system/video 内容入口；`/products/robotaxi` canonical/redirect。
