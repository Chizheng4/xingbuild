# v0.3.1 精简全站视觉与手机导航

## 要解决的问题

- 手机导航展开后仍暴露正文，没有形成完整、干净的导航状态。
- 页头和页脚重复作者、所在地与更新时间，品牌识别不够克制。
- 页面依赖大量横线和边框分段，视觉偏工程文档。

## 完成结果

- 手机菜单使用 Phosphor 图标，展开后变为关闭图标和全视口覆盖层。
- 菜单展开时锁定正文滚动，并把主内容与页脚设为 `inert`；支持 `Escape`、关闭按钮和选择导航恢复页面。
- 页头只保留 `xingbuild`；页脚只保留 `© 2026 xingbuild`。
- 首页全站更新时间入口删除；内容自身的发布日期、状态与证据更新时间继续保留。
- 首页、观察、正文、作品、作品详情和关于我的装饰性横线与边框全部删除，改用排版、对齐和留白建立层级。
- 架构图保留表达业务对象关系所必需的语义线。

## 验证结果

- `design-qa.md` 最终结果为 `passed`。
- 桌面 `1440px` 与手机 `390px` 验证首页、观察列表、短观察、分析长文、作品、作品详情和关于我。
- 全部核心页面无横向溢出、无非架构语义边框。
- 手机菜单覆盖完整视口，正文和页脚不可交互，关闭与导航恢复正常。
- 浏览器控制台无错误。
- `npm run release:check` 通过，13 项测试全部通过。
- 未推送 GitHub、未发布 EdgeOne、未修改域名。
