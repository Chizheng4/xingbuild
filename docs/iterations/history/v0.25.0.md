# v0.25.0 产品、内容与站点发布三层架构重建

## 结果

- 本地产品版本：`v0.25.0`。
- 实现提交：`72816c5d60e0638c99a58f6277881e66d26f4dee`。
- annotatedTag：`v0.25.0`（history 收口后创建）。
- clean：`true`（history 收口、tag 与 preflight 后）。
- 父版本：`v0.24.37` / `bd97ed78b8cb30cb906689a131a8c612890bdc69`；v0.24.38 未形成正式 tag，不单独发布。
- 本版本将 ProductRelease、ContentReleaseIntent 与 SitePublication 分成独立对象；产品与内容只提交意图，唯一 SitePublication Coordinator 负责整站快照、站点 lease、单一 EdgeOne transport、传播、公网验证、resume 和 finalize。
- 本轮不 push、deploy 或线上发布。

## 范围

- 产品 transport 不再丢失 active 内容；内容 transport 不再覆盖产品或依赖旧产品 dist。
- 同一物理站点的产品/内容 transport 串行；失败保留 `recoverable`、`failure` 与 `recoveryId`，resume 复用同一 `deploymentId`，失败不 finalize。
- 只有协调器可以调用 EdgeOne；Deploy Success 不等同于发布完成，必须同时取得 deployment JSON、产品/内容 manifest、目标页面与媒体公网证据后才返回成功。
- 产品方案通过 `contentImpact`、影响目标/路由/字段和兼容证据声明内容兼容性；`breaking`、`migration-required` 或 `unknown` 在发布前形成 Product Incident 并硬停止。
- 保留既有产品/内容命令作为兼容入口；不修改 UI、IA、schema、上游事实、既有内容正文或 v0.24.37 及更早 tag/history。
