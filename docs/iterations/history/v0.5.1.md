# v0.5.1 中文语义换行与公网验收修订

## 解决的问题

- 首页和文章标题会拆开“构建”“同时”等完整中文词组；
- 标题、段落、列表与提示之间缺少统一的相邻语义节奏合同；
- `v0.5.0` 的生产发布与公网验收状态尚未进入版本记录。

## 完成范围

- 为 display、页面、文章和重点标题建立原生中文语义换行规则；
- 确认页面语言为 `zh-CN`，保留不支持 `auto-phrase` 浏览器的自然回退；
- 明确正文段落、标题、提示和章节之间的单一间距责任；
- 增加语言、语义换行与阅读 flow 的视觉合同测试；
- 完成七档 Chrome 验收与版本状态收口。

## 完成状态

- 工程实现、七档本地 Chrome 验收和 `npm run release:check` 已完成；
- 本地提交与 `v0.5.1` 标签已完成；
- 未推送 GitHub，未发布 EdgeOne，未修改域名。
