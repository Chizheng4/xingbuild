# v0.11.0 总体结构与高密度视觉母版

## 问题

网站在真实内容尚未准备好时，使用放大的定位 Hero、隐藏模块区或孤立的一行空态承载页面，导致 Robotaxi 和观察页面缺少明确阅读对象，并出现无责任的大面积空白。企业经营体系也需要从多入口知识浏览投影收敛为一张可直接阅读、可操作的总览图。

## 实现

- 根路径与 `/robotaxi` 复用同一 PracticePage；旧作品路径保留兼容重定向但不进入新导航。
- 建立 LayoutShell、TwoColumnLayout、Practice、PracticeModule、BriefProjection 和统一查询边界；没有符合条件的模块或简讯时不创建占位内容、猜测图片或推测链接。
- Robotaxi 使用紧凑站点定位条、真实作品 h1、已确认摘要和事实边界；无模块时使用同一对象的紧凑空态，不再使用 display Hero、伪模块或装饰分割线。
- 观察使用定位条、页面 h1 与配置化当前状态；两篇既有 ObservationPublication 完整保留在底层，但不能自动改写为 BriefProjection、信息流或右栏填充。
- 企业经营体系只公开一张由 frameworkModel 驱动的总览 GraphCanvas；说明固定于图下，支持 hover/focus 预览、click/键盘选择、有限拖动和复位。新增节点碰撞、标签安全、边终点与边不穿无关节点的校验。
- 收敛 header、容器、gutter、双栏、画幅与关系空间 token，保持暖白、墨色和有限赭色品牌；About 只无损适配共同 shell。

## 验证

- `npm run release:check` 通过，45 项自动测试全部成功；
- `git diff --check` 通过；
- 真实浏览器串行验证 1440、1024、768、557、520、390、320：根页面与观察空态无横向溢出、无空 rail、无伪内容；557/520 保持紧凑行内导航，小于 520 为全屏菜单；
- 1440 企业总览为 940×588、7 节点且无重叠；390 为 335×300，选中说明、有限平移与复位正常；console error/warning 为 0；
- 结构视觉专业验收确认 Robotaxi 与观察空态完整、无装饰分割线，且现有空白来自已确认的“无真实内容”状态，不以伪内容填补。
