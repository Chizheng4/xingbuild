# v0.19.0 企业经营体系常青长文与图形内容能力

## 目标

- 将企业经营体系从页面专用架构图运行时收束为可持续更新的常青长文；
- 复用 `RichDocument`、`ReadingTOC` 和受控 figure block；
- 让图形源由锁定的开源 CLI 在内容准备阶段生成 desktop/mobile SVG；
- 建立单文章内容检查、独立提交、产品版本/tag 不变的发布边界。

## 已完成

- `EvergreenArticlePublication`、`ReadingTOC` 和 `RichDocument` 已形成稳定文章投影；
- figure 只声明 `sourcePath`、`renderer`、`layoutPreset`、`alt`、`caption`，不声明页面坐标和移动端特例；
- Mermaid CLI 11.16.0 与 LikeC4 adapter 锁定并通过 source-driven 生成和失败清理专项；
- 旧 `?view=digital-implementation` 兼容到文章锚点，不再作为第二套局部页面运行时；
- 1440/768/390 真实页面验证通过，文章目录、移动折叠、SVG 响应式和无横向溢出通过；
- 文章单 slug 检查与独立发布边界完成，未改变 Observation 内容合同。

## 发布结果

- commit/tag：`43a08ab6200405c753b5766f75f544827a1e38e8` / `v0.19.0`；
- GitHub main 与 tag 已推送并对齐；
- EdgeOne deployment：`dphqeng287ul`；
- 公网 `release.json` 与 `content-manifest.json` 同版本、同 SHA；
- 公网文章与移动目录验收通过，工作区 clean。

## 产品结论

本版本解决了“企业经营体系长文和图形可以作为内容持续发布”的问题，但没有完成通用页面注册平台或完整 `VisualizationHost`。后续应先验证页面组合注册能力，再按真实重复需求建设能力展示控件；不得回到页面专用图形运行时。
