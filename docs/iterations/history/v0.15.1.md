# v0.15.1 画布平移与节点点击责任修订

## 问题

在真实鼠标点击总览“数字化实现”节点时，画布父级同时建立 pointer capture，可能将节点点击误判为拖动并抑制下钻 click。

## 实现

- 画布的 pointerDown 只接受背景和非交互层；`.graph-node`、button、链接和表单控件不进入 pan session。
- 节点继续直接承担 click、Enter、Space；拖动责任仅保留在画布背景，背景拖动后的 click 抑制仍只覆盖该拖动手势。

## 验证

- 自动：节点/背景 pointer responsibility 合同、`npm run release:check`、closeout/preflight。
- 浏览器：390、320、1440 的真实 click、Playwright click、Enter、Space、普通节点选择、背景平移、复位和返回焦点。
