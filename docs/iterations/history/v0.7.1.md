# v0.7.1 本地启动终端交互收敛

## 问题

Vite 开发服务器默认读取启动终端的普通键盘字符。误触 `h` 会显示快捷键帮助，误触 `r` 或 `q` 还可能重启或退出，使一键启动窗口暴露不必要的交互控制。

## 修订

- `start-xingbuild.command` 启动 Vite 时将标准输入连接到 `/dev/null`；
- 保留固定 4317 端口、自动打开网站、本地/线上地址和前台运行；
- `Control-C` 继续通过终端信号停止服务；
- 自动测试固定“不读取普通字符”的启动合同。

## 验证

- Shell 语法检查通过；
- 临时端口实际启动后不再显示 `press h + enter`；
- `Control-C` 实际停止验证通过；
- `npm run release:check` 通过，28 项测试全部成功。
