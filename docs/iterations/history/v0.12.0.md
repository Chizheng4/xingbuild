# v0.12.0 紧凑身份、双形态观察与作品母版

## 问题

站点需要从“作品与观察共用旧页面投影”收敛为稳定的作者入口、作品母版与两种明确的观察阅读形态。读者层不应暴露内容生产治理结构；真实内容也必须通过可复制的内容对象进入页面，而不是继续依赖页面专用投影。

## 实现

- Header 采用同基线、单行的 `xingbuild 金星 Xingjin` 身份组；根路径恢复为作者首页，`/robotaxi` 保持独立实践页，旧作品路径安全兼容。
- 建立首页两项核心实践入口；Robotaxi 与企业经营体系统一按“短作品说明 → 真实视觉证据”组织。Robotaxi 当前无获批准模块媒体时不制造截图、模块或泛链接。
- 收敛 1280 shell、作品双栏与 736px 观察集合列；无有效 Brief 时不保留空 rail。
- ObservationPublication 新增受校验的显式 `presentation: brief | article`。本轮八条 scheduled 观察使用 Brief，既有两篇文章保留直接访问兼容但不自动进入简讯流。
- Brief 固定为事件日期与主体、独立维度、事实陈述、最终来源行四个阅读角色；用父级 gap 表达相邻关系，不使用边框、卡片或装饰分隔线。
- Article 收敛为唯一标题、维度、摘要、普通正文与末行内联来源；事实概览、范围与事实、经营影响、目录、来源列表和其他治理数据继续留在底层内容合同，不进入读者 UI。
- 企业经营体系继续复用同源总览模型、节点关系与可选择/平移/复位交互；本轮不改变概念、边集或几何合同。
- 短内容页取消 `main` 的剩余视口填充，footer 按内容后的语义关系自然流动。
