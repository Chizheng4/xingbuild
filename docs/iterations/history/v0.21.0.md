# v0.21.0 Practice 内容独立发布能力

## 目标

为单一 Practice id 提供独立的检查、提交、push、部署和公网验收能力，使内容运营不再与产品页面工程、产品版本或 tag 绑定。

## 已完成

- 新增 `practice:scope-check -- --id <practiceId>`，仅检查目标 Practice 的安全范围、schema、生命周期、媒体审批、文件存在性与 hash。
- 新增 `publish-practice.command --id <practiceId>`，复用既有构建、站点测试、push、EdgeOne 部署和公网验证边界；不创建产品版本/tag。
- 新增 `verify-practice-release`，验证 `/products` 目标 Practice 投影、媒体路径以及 release/content manifest 的 SHA。
- 对媒体引用范围、生命周期、公开状态、hash 和 unsafe archive path 建立硬失败门禁；未引用的内部或历史记录不投影到读者界面。
- 未修改 Practice schema、页面结构、视觉系统、Robotaxi 独立网站、Observation/Article/About 发布合同。
