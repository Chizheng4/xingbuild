# v0.9.0 全站内容卡片与页面结构收敛

## 问题

首页、观察、作品和关于我使用多套桌面坐标与内容语法；通用 128px 页面间距制造无语义空白，同类观察和作品在不同页面又使用不同字段、结构和交互。

## 实现

- 将四个默认页面的 Intro、集合和正文收敛到同一内容主轴；
- 删除 Page Intro 桌面 rail、单一年份 rail、About 常驻目录和重复英文栏目标签；
- 建立共享 ContentCard、ObservationCard、WorkCard 与 CardGrid；
- 首页和栏目页消费相同卡片组件、字段顺序、整体链接和响应式投影；
- 观察卡片固定为标题、摘要、类型/主题/日期，作品卡片固定为标题、问题摘要、状态/更新时间；
- 删除 ObservationFeature/ObservationRow、“继续阅读”、远端箭头、作品关键词和列表详情投影；
- 建立独立卡片 surface、border、radius、hover、focus、active 与 reduced-motion token；
- 用 Page Intro→集合、Section→Section、Section Intro→Grid、Card→Card 等关系 token 替代通用 128px PageStack gap。

## 验证

- `npm run release:check` 通过，32 项测试全部成功；
- 真实浏览器验证覆盖 1440、1024、768、557、520、390、320px；
- 四页主轴一致，1440/1024 两列、768 以下同源单列，无卡片或页面横向溢出；
- 每张卡片只有一个原生主链接，同类型 DOM 与字段顺序完全一致；
- 390px 全屏菜单、滚动锁定与 Escape 恢复正常，557/520 保持行内导航；
- 卡片 focus-visible、accessible name、点击和 reduced-motion 合同通过；
- v0.8.0 企业认知架构节点、投影、轨道 marker 和最窄宽度回归通过；
- 结构视觉 task 独立完成结构、视觉、卡片一致性、响应式与浏览器专业验收。

## 已知边界

- 受控浏览器不能稳定派发 CSS `:hover` 与原生 Enter 导航，但 hover 合同已由源码和测试锁定，原生链接焦点与语义成立；独立专业验收确认不构成产品阻塞；
- 当前观察和作品数量较少，未来内容增长仍须保持 schema，不通过截断或页面专用变体制造等高；
- 768px 按内容驱动断点进入单列，不为填满空间强行保留双列。
