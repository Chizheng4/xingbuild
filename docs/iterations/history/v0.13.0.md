# v0.13.0 信息架构、展示母版与富文本内容系统

## 问题

此前首页、Robotaxi、企业经营体系、观察与关于我仍存在各自的内容投影和页面结构；后续新增真实内容会继续推动页面或组件改动，且一级导航、阅读路径与产品归属不够清晰。

## 实现

- 一级导航固定为 `B端产品 / 经营观察 / 关于我`；`/observations` 保持由更多观察和内容上下文进入的集中阅读页。
- 首页只保留一次定位语 H1，并直接复用同源的最新 B端产品与最新经营观察；观察 Rail 只在外层出现一次。
- 建立统一 `ShowcaseLayout` 与 `SystemStage`：1280px shell 内采用 952px 主展示区、24px 间距、304px Rail，以及 208px 说明列、20px 间距、724px 系统展示列。
- Robotaxi 公开名称固定为“Robotaxi运营平台”；批准媒体、读者互动与内部 provenance 保持分层，页面不公开运营中控台分组或 loopRelation。
- 企业经营体系归入经营观察，保留同源总览图的选择、键盘、平移、复位与几何合同；节点权威说明移入左说明列，删除图下说明面板。
- ObservationBlock 由显式 Brief/Article 投影驱动，集中观察、长文与关于我共享 ReadingShell；Article/About 改为 RichDocument 受控块投影。
- 新增 `content/products`、`content/business-observations`、`content/profile` 内容入口。后续增加模块、已批准媒体、观察、长文或关于我内容无需再改页面组件或视觉 CSS。

## 验证

- 自动检查：`npm run release:check`、`git diff --check`。
- 浏览器预检：1440、1280、1024、768、557、390、320 宽度下验证三项导航、紧凑 Header、Showcase 几何、单列转换、观察阅读列、框架选择/平移/复位、返回路径与无横向溢出。
- 发布前检查：`npm run release:closeout-check` 与 `npm run release:preflight`。
