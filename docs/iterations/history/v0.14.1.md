# v0.14.1 Framework 投影标题层级修订

## 问题

`v0.14.0` 的 `FrameworkDescription` 只让选中节点标题跟随投影根标题递进，内部“定义 / 作用 / 直接关系”仍固定为 `H3`。因此首页同源投影产生 `H2 → H3 → H3`，内部说明与选中节点语义并列。

## 实现

- 内部说明标题由选中节点标题级别加一生成；来源页为 `H1 → H2 → H3`，首页为 `H2 → H3 → H4`。
- CSS 分开处理选中节点标题与内部说明标题，使 `H4` 继承既有说明视觉，不改变字号、间距或色彩。
- 新增首页与来源页投影的标题层级回归合同。

## 验证

- 自动：`npm run release:check`、`git diff --check`、`npm run release:closeout-check`、`npm run release:preflight`。
- 浏览器：本地与生产检查首页和企业经营体系来源页的标题顺序、框架选择与响应式无回归。

## 明确不做

- 不修改 Framework 模型、概念、边集、箭头、文案、视觉或交互；不扩展任何 v0.14 backlog。
