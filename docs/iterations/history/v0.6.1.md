# v0.6.1 对象内部构图节奏修订

## 解决的问题

- `v0.6.0` 正确解决了栏目级双重留白，但 `.object-stack` 把内容对象层级错误映射为统一的 `--rhythm-object` 大间距；
- 重点观察与首页作品的 Identity、Proposition、Evidence、Action 之间均约 48px，对象内部被视觉拆散。

## 完成范围

- 将 ObjectStack 默认相邻关系从 `object` 修正为 `relate`；
- 保持 PageStack、SectionFlow、CollectionFlow 和六层视觉结构不变；
- 补充对象内部关系的结构合同测试；
- 完成七档对象节奏测量与关键页面桌面、手机回归。

## 验证结果

- 重点观察内部三组关系由桌面 24px 连续收敛到手机 16px；
- 首页作品 Identity → Proposition 与 Proposition → Evidence 同样由 24px 收敛到 16px；
- 对象之间继续为桌面 64px、手机 40px，栏目之间继续为桌面 128px、手机 64px；
- 首页、观察、短观察、长文、作品、作品详情和关于我无横向溢出或控制台错误；
- `npm run release:check` 通过。

## 完成状态

- 本地提交与 `v0.6.1` 标签已完成；
- 未推送 GitHub，未发布 EdgeOne，未修改域名。
