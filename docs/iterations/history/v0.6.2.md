# v0.6.2 序号语义与手机导航简化修订

## 解决的问题

- 首页栏目与作品同时使用 `01 / 02`，让数字同时像页面顺序、作品索引和装饰符号；
- 核心能力、无序问题和作品详情并列主题使用了没有顺序含义的编号；
- 删除数字后可能遗留索引 rail、空白列和异常缩进；
- 手机展开菜单需要固定为长期最小合同，避免后续增加无价值信息。

## 完成范围

- 删除首页 SectionIntro 装饰序号、WorkSummary 视觉索引及 `work.index` 字段；
- 将“能够解决的问题”改为无序列表，删除核心能力和作品并列主题自动编号；
- 删除 index rail、视觉索引样式和相关响应式空列；
- 保留年份、日期、架构流程、四平面、版本与 404 等语义数字；
- 保持手机菜单既有内容、排版、触控和交互合同。

## 验证结果

- 七档 Chrome 验证首页、作品、关于我、作品详情和观察列表，共 35 组页面与视口组合无失败；
- 删除序号后内容左侧对齐，不存在空白索引列或横向溢出；
- Robotaxi 架构五个节点、观察年份与日期继续显示；
- 390px 手机菜单保持三个入口、约 23px 衬线、56px 触控高度、12px 项间距、全屏覆盖与滚动锁定；
- Escape 正常关闭菜单并恢复页面滚动；
- `npm run release:check` 通过。
