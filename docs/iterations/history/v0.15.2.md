# v0.15.2 Robotaxi 媒体生命周期与公开投影修订

## 问题

Robotaxi 的上游 approved manifest 已将四项历史媒体转为 superseded、suspended、paused 或 revoked；xingbuild 仍将 manifest 误当作全部公开集合，无法如实保留状态又隐藏读者投影。

## 实现

- manifest 成为生命周期与 provenance 记录；公开查询只接受 active + approved + public 的完整单项链路。
- 保留四项历史文件、SHA-256、版本、commit、approvalRecord 与 reviewRecord，在内部 archive 中核验；当前公开投影为零。
- content-only 范围与发布入口支持一个媒体 manifest 及必要 archive/public 资产，不改变产品版本号或页面组件。

## 验收

- 状态矩阵、hash、内容范围、Practice 投影与生产构建合同通过。
- 首页与 `/products` 无历史媒体、空框或残缺模块；其他页面与响应式回归通过。
