# v0.15.0 企业经营体系总览至数字化实现局部视图

## 问题

企业经营体系已有权威的数字化实现架构模型，但读者只能在总览中选中“数字化实现”，不能在同一阅读路径中继续理解业务架构、B端产品架构、数据架构、技术、工程、系统和经营反馈之间的关系。

## 实现

- 总览中的“数字化实现”成为唯一直接下钻节点，使用 `?view=digital-implementation` 进入既有同源架构；未知 view 回退总览。
- 当前 architecture 统一驱动节点、关系、标签、说明、默认选中、复位与 aria-live；局部不再读取总览边集。
- 显式返回使用 replace 回到总览，并恢复“数字化实现”节点的选中与焦点；浏览器 Back、刷新和直接局部 URL 保持可用。
- 桌面保持 16:10 SystemStage；520px 以下局部消费模型已有 350×1010 mobile projection，并按世界与可视区差值限幅纵向平移。
- 扩展 overview 与 digital-implementation 的 desktop/mobile 几何校验，锁定节点、端点、无关穿越和投影边界。

## 验证

- 自动：`npm run release:check`、`git diff --check`、`npm run release:closeout-check`、`npm run release:preflight`。
- 浏览器：1440、1024、768、557、390、320 下验证总览进入、局部选择、平移、复位、Back、返回、直接/刷新局部 URL、未知 view、无横向溢出与 console。

## 明确不做

- 不增加第二个局部入口、node query、局部图导航、详情页或第二张公开页面。
- 不修改框架概念、节点、边、关系标签、观察、Robotaxi、About、导航或 backlog。
