# v0.5.0 根本视觉构图优化

## 解决的问题

- 桌面首页 Hero 起点过低、标题列过窄；
- 字体角色缺少清楚分工；
- 手机 Hero 说明与首项内容之间节奏偏弱。

## 完成范围

- 重构首页 Hero 网格、标题宽度和垂直位置；
- 固定衬线与无衬线的内容责任；
- 优化手机 Hero 与最新观察进入节奏；
- 固定全小写 `xingbuild` wordmark；
- 回归核心页面、导航断点和长文阅读。

## 完成状态

- 工程实现、本地多宽度 Chrome 验证和 `npm run release:check` 已完成；
- 本地提交与 `v0.5.0` 标签已完成；
- 用户已完成生产发布；
- 2026-07-25 公网 Chrome 验收确认整体视觉构图成立；
- 公网验收发现中文词组可能在标题中被拆开，转入 `v0.5.1` 修订。
