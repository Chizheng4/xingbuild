# v0.20.0 页面定义注册与组合渲染

## 目标

- 建立受控 `PageDefinition` registry（页面注册表）；
- 用共享 composition renderer（组合渲染器）承接既有页面组合；
- 证明同一组合的新页面只需页面定义和已批准内容引用，不新增页面 JSX、页面 CSS 或重复路由分支。

## 已完成

- `HomeComposition`、`ShowcaseComposition`、`CollectionComposition`、`ReadingComposition` 纳入共享页面定义与渲染路径；
- `/about` 完成低风险迁移，并以同组合 fixture 验证配置化接入；
- 页面定义、路由、区域和内容引用校验在无效时硬失败；
- 保持既有 URL、内容对象、视觉 token、Header、Footer、ReturnNavigation、Observation/Article/Practice 边界和内容发布命令不变；
- 桌面、紧凑宽度、手机、键盘/tap、返回、直接访问、无横向溢出与无空区域验收通过。

## 产品结论

本版本解决了“页面组合可以受控注册和复用”的问题，但没有实现 `CapabilityHost / VisualizationHost`、LikeC4 原生多视图运行时、Robotaxi embed 或 Practice 独立发布 CLI。下一版本必须从路线图候选中只选择一个最小目标。
