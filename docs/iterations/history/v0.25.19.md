## 版本边界

- 父版本：`v0.25.18` / `cca1f5970b695baee8435fca453a98c4623782e2`
- 正式方案：[`docs/design/v0.25.19 内容收据与活动站点投影单一身份方案.md`](../../design/v0.25.19%20内容收据与活动站点投影单一身份方案.md)
- 本版本为 Engineering 能力版本；不执行产品或内容 transport。

## 实现与不变量

- `ContentReleaseReceipt.receiptHash` 仅表示不可变 package receipt；`ActiveContentProjection.projectionHash` 仅表示 immutable receipt、authoritative `ContentSlotRegistry` active slot、`PublicationLineageBinding` 与 `ProductArtifact` 的确定性活动投影。
- 所有 active reader、ActiveContentSet、manifest、SitePublication 和 Coordinator publicVerify/finalize/resume 复用同一个 projection 对象，不在调用点重复拼接或重算身份。
- legacy projection 明确隔离，不能与新 projection 混组；同一 tuple 生成稳定 projection/snapshot/idempotency identity，同一 publication resume 不重复 deployment。
- 真实 34 active corpus、Robotaxi replacement、About recoverable package、drift/CAS/失败保留旧 active 回归覆盖；不修改 UI、IA、schema、视觉、正文、审核、媒体或既有 contentReleaseId。

## 验收边界

产品/视觉独立验收与产品公网完整验证后，才允许继续后续内容 task；本版本完成前保持内容 task 停止。
