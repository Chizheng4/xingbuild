# v0.1.4 正式域名体系

## 目标

- 保持 `xingbuild.top` 为个人网站唯一主域名。
- 让 `www.xingbuild.top` 通过 301 永久跳转至主域名。
- 保持路径和查询参数。
- 保持 `robotaxi.xingbuild.top` 由 Robotaxi 独立项目发布。

## 完成结果

- EdgeOne 重定向配置已经进入版本、构建产物和项目检查。
- 本地稳定版本、Git 提交和 `v0.1.4` 标签已经形成。
- `xingbuild.top`、`www.xingbuild.top` 与 Robotaxi 子域名已经完成独立域名配置。

## 边界

- xingbuild 与 Robotaxi 继续使用独立代码、版本和发布流程。
- 本地版本完成、GitHub 同步和 EdgeOne 生产发布是不同状态。
