# xingbuild 运营文档入口

本目录只服务内容采集、事实审核、内容发布和运营问题治理，不定义网站产品架构，也不决定产品版本。

## 唯一入口

- [内容运营与发布问题清单](内容运营与发布问题清单.md)：所有运营阻断、发布工具问题和关闭验证。
- [Slug 级内容审核终端命令交接](Slug级内容审核终端命令交接.md)：内容审核命令合同。
- [经营观察信息源与覆盖合同](经营观察信息源与覆盖合同.md)：来源注册、采集窗口和覆盖台账合同。

## 转入产品候选

运营问题只有在影响公开内容对象、页面结构、视觉/响应式或发布能力合同的情况下，才在 `docs/iterations/candidates/` 创建候选记录，并在本目录问题清单保留来源 ID。运营问题清单不复制产品方案正文。

内容日常更新、审核和发布不进入 `current.md`，不创建产品版本，不等待 Engineering。
